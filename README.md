## 简介

长时间穿靴子会把脚捂出汗：汗脚分三级推进，三级的臭脚还会感染真菌——掉血、打喷嚏、传染给朋友。把汗倒进玻璃瓶做成汗液瓶（三级汗液发生质变，按靴子材质带风味），发酵靴能酿出 buff 饮品；想治好，只能坐凳子上泡脚。

**核心特色**

- **汗脚三级制**：穿靴累计 2/4/6 分钟依次汗化，等级越高越遭罪（2 级脚下打滑、3 级手持汗靴反胃+丢地污染空气）；下界炎热，汗化速度 ×2
- **三级质变**：汗脚 3 级倒汗，汗液按靴子材质质变成五种风味瓶——不同颜色、不同附加效果，是「从夯到拉」收集进度的核心
- **真菌感染**：汗脚 3 级继续穿靴会感染真菌——持续掉血、喷嚏粒子、光脚散臭、传染给朋友；唯一解法是花露水泡脚
- **洗脚动画**：坐凳 + 脱鞋 + 盆里泡脚，下半身皮肤会按你选的肤色「脱裤」（支持滴管取色器 + 跨端同步）
- **整蛊向**：汗液瓶可以砸给朋友喝（2 级反胃、3 级中毒），洗脚水也能装桶送人

## 玩法机制

### 汗脚三级

穿任意靴子累计达到时限，靴子「汗化」——改名「充满〈玩家名〉汗液的〈原靴名〉（等级X）」、冒汗粒子、挂上汗脚效果：

| 等级 | 穿戴累计 | 效果 |
| --- | --- | --- |
| 1 级 | 120 秒 | 冒汗粒子，倒汗可做 1 级汗液瓶 |
| 2 级 | 240 秒 | + 脚下打滑（摩擦变小，像踩冰） |
| 3 级 | 360 秒 | + 手持汗靴持续反胃；丢到地上散发绿色臭味粒子、污染附近玩家（含自己） |

- **下界**：炎热环境汗化速度 ×2（整蛊彩蛋）
- **脱鞋**：汗脚效果保留，每 60 秒降一级，1 级到头彻底消失
- **倒汗不清汗脚**：倒汗只产瓶，汗脚只能靠泡脚清除

### 倒汗与三级质变

主手持汗靴 + 副手空玻璃瓶 + 潜行右键 → 靴子还原，产出汗液瓶。

**质变规则（0.1.4+）**：

| 汗脚等级 | 产物 |
| --- | --- |
| 1-2 级 | 普通汗液瓶（名字带等级 I/II，无风味） |
| 3 级 + 原版/本 mod 材质靴 | **风味汗液瓶**（质变：名字无等级，保留完整三级效果 + 风味附加效果，瓶身按风味染色） |
| 3 级 + 其他 mod 靴子 | 普通三级瓶（带等级 III，兼容未知材质） |
| 3 级 + 发酵靴 | 汗液饮品（正面 buff，见下文） |

### 风味图鉴

| 靴子材质 | 风味 | 瓶色 | 附加效果 |
| --- | --- | --- | --- |
| 皮革 | 醇厚 | 棕 | 回饱食度翻倍（2 点） |
| 铁 | 铁锈 | 红褐 | 虚弱 15 秒（唯一的负面风味——便宜材料，汗也差劲） |
| 金 | 金贵 | 亮黄 | 幸运 60 秒 |
| 钻石 | 凛冽 | 青蓝 | 抗性提升 20 秒 |
| 下界合金 | 硫磺 | 橙金（火抗药水色） | 火焰抗性 30 秒 |

集齐五种风味解锁进度「从夯到拉」。

### 汗液瓶效果

| 等级 | 喝下去 |
| --- | --- |
| 1 级 | 恢复 1 点饥饿值（半格），饱食度 |
| 2 级 | + 反胃 10 秒 |
| 3 级 | + 中毒 3 秒（风味瓶再叠风味附加效果） |

效果和饱食度直接显示在瓶子的 tooltip 上，与原版药水一致。

### 真菌感染

汗脚 3 级后继续穿靴 60 秒 → 感染真菌：

- 每 3 秒掉 1 点血（魔法伤害，无视护甲）
- 喷嚏粒子（可关闭）
- **传染**：3 格内站着的玩家会被传染（每 3 秒检查）；光脚散臭（5 格内反胃）
- **唯一解法**：花露水倒进有水的洗脚盆 → 变成药水洗脚水 → 坐凳泡脚治愈

### 泡脚与洗脚

1. 放一个**洗脚盆**，用**水桶**倒水（或空桶舀水、药水可直接进盆）
2. 坐**凳子**（空手右键，自动脱鞋）
3. 赤脚泡水 15 秒 → 汗脚清除，盆水变浑（可用空桶收集「洗脚水桶」）
4. 花露水（水瓶 + 任意两种小花合成）倒进盆里 → 药水洗脚水，泡脚治真菌

**洗靴子**：汗靴扔进水里泡 15 秒自动洗净（可配置关闭）。

### 发酵靴与饮品

- **合成**：皮革靴 + 糖
- 穿它汗脚发酵，**3 级倒汗**产出「〈玩家名〉的汗液饮品」（不是汗液瓶）
- 护甲 1 点（同皮革），tooltip 直接显示
- **喝**：30 秒 迅捷 + 跳跃提升 + 力量 + 幸运

## 配置

按 **J** 打开配置界面（或 背包右上角 ⚙ 按钮 / Mods 列表 → Config）。配置分 4 类：

- **汗脚**：汗化时间（120/240/360 秒）、降级速度、打滑、粒子
- **真菌**：开关、掉血、传染范围/间隔、散臭
- **物品与饮品**：瓶效果时长（反胃/毒/buff）、洗靴、饮品时长
- **表现效果**：泡脚脱裤、肤色 tint、取色器、调试开关

> 服务端配置权威：多人游戏时配置以服务端为准（存 `config/sweatyfeet-server.toml`）。

- Minecraft **1.21.1**
- **NeoForge** 21.1.x（Java 21）
- **player-animator** ≥ 2.0.4（泡脚动画前置，[Modrinth](https://modrinth.com/mod/playeranimator)）
- **Patchouli**（可选，装了就发手册；不装不影响玩法）

## 安装方式

1. 下载本仓库 `Neoforge-1.21.1` 分支的 `sweatyfeet-NeoForge-1.21.1-0.1.5.jar`
2. 放入 `.minecraft/mods/`
3. 启动游戏（客户端和服务端**都要装**）

## 常见问题

**真菌感染怎么治？**
花露水倒进有水的洗脚盆 → 药水洗脚水 → 坐凳泡脚。没有别的办法（命令除外）。

**汗脚怎么消除？**
泡脚 15 秒。倒汗不清汗脚，脱鞋只降级。

**汗液瓶怎么获得？**
主手汗靴 + 副手空玻璃瓶 + 潜行右键倒汗。靴子必须已汗化（穿满 2 分钟以上）。

**为什么我 1-2 级倒出的瓶没有风味？**
这是三级质变机制（0.1.4+）：1-2 级只出普通瓶，**汗脚 3 级**倒汗才会按靴子材质质变成风味瓶。

**风味瓶的颜色代表什么？**
每种风味一个药水色（硫磺=金色、凛冽=青蓝等），颜色对应附加效果，见上文风味图鉴。

**发酵靴有护甲吗？**
有，1 点（同皮革），tooltip 上直接显示。

**喝汗液瓶回多少饱食度？**
1 点（半格）；醇厚风味翻倍 2 点。

**手册怎么获得？**
进世界自动发一本（装了 Patchouli）；背包多本自己丢。

**服务端要装吗？**
要。本 mod 是双端 mod，服务端不装玩法逻辑不生效。

**可以放进整合包吗？**
可以，MIT 协议，注明来源即可。

**按 J 没反应？**
键位可能被其他 mod 占用——进「选项 → 控制」改键，或用背包右上角 ⚙ 按钮。
