## 简介

长时间穿靴子会把脚捂出汗：汗脚分三级推进，三级的臭脚还会感染真菌——掉血、打喷嚏、传染给朋友。把汗倒进玻璃瓶做成汗液瓶（三级汗液发生质变，按靴子材质带风味），发酵靴能酿出 buff 饮品；想治好，只能坐凳子上泡脚。

**核心特色**

- **汗脚三级制**：穿靴累计 2/4/6 分钟依次汗化，等级越高越遭罪（2 级脚下打滑、3 级手持汗靴反胃+丢地污染空气）；下界炎热，汗化速度 ×2
- **三级质变**：汗脚 3 级倒汗，汗液按靴子材质质变成五种风味瓶——不同颜色、不同附加效果，是「从夯到拉」收集进度的核心
- **真菌感染**：汗脚 3 级继续穿靴会感染真菌——持续掉血、喷嚏粒子、光脚散臭、传染给朋友；唯一解法是花露水泡脚
- **洗脚动画**：坐凳 + 脱鞋 + 盆里泡脚，下半身皮肤会按你选的肤色「脱裤」（支持滴管取色器 + 跨端同步）
- **整蛊向**：汗液瓶可以砸给朋友喝（2 级反胃、3 级中毒），洗脚水也能装桶送人

## 玩法机制速览

- **汗脚三级**：穿靴累计 2/4/6 分钟依次汗化；2 级脚下打滑、3 级手持汗靴反胃 + 丢地污染；下界汗化速度 ×2；倒汗不清汗脚，泡脚才根治
- **三级质变**：汗脚 3 级倒汗，汗液按靴子材质质变成五种风味瓶——不同瓶色、不同附加效果，是收集进度的核心
- **真菌感染**：汗脚 3 级继续穿靴会感染真菌——持续掉血、喷嚏粒子、光脚散臭、传染给朋友；唯一解法是花露水泡脚
- **泡脚洗脚**：坐凳 + 盆里泡脚 15 秒清除汗脚、治愈真菌；汗靴扔水里 15 秒自动洗净
- **发酵饮品**：穿发酵靴让汗脚发酵，3 级倒汗产出正面 buff 饮品（迅捷/跳跃提升/力量/幸运）

> 完整机制、数值表与合成配方（风味图鉴、各等级具体效果）都在游戏内**手册**里，按 **H** 打开。本页只列玩法梗概。

## 配置

按 **J** 打开配置界面（或 背包右上角 ⚙ 按钮 / Mods 列表 → Config）。配置分 4 类：

- **汗脚**：汗化时间（120/240/360 秒）、降级速度、打滑、粒子
- **真菌**：开关、掉血、传染范围/间隔、散臭
- **物品与饮品**：瓶效果时长（反胃/毒/buff）、洗靴、饮品时长
- **表现效果**：泡脚脱裤、肤色 tint、取色器、调试开关

> 服务端配置权威：多人游戏时配置以服务端为准（存 `config/sweatyfeet-server.toml`）。

## 安装要求

- Minecraft **1.21.1**
- **Fabric Loader** ≥ 0.15.11（Java 21）

**必需依赖**

- **Fabric API** ≥ 0.116.0
- **player-animator** ≥ 2.0.4（泡脚坐下动画依赖；1.21.1 对应版本 `2.0.4+1.21.1`）

**可选依赖**

- **ModMenu**（推荐——配置界面入口之一）
- **Patchouli**（帕秋莉手册——装了就发游戏内手册，7 章 29 条目；不装不影响玩法）

## 安装方式

1. 下载本仓库 `Fabric-1.21.1` 分支的 `sweatyfeet-Fabric-1.21.1-0.1.6.jar`
2. 放入整合包的 `.minecraft/mods/`（如 1.21.1-CCB）
3. 启动游戏（客户端和服务端**都要装**）

## 整合包与服务端

- **可以放进整合包**（MIT 协议，注明来源即可）
- 客户端 + 服务端都要安装本 mod（玩法逻辑在服务端，动画/渲染在客户端）
- **服务端配置权威**：多人游戏以服务端 `config/sweatyfeet-server.toml` 为准；客户端配置只影响本机显示（如肤色 tint）
- 不依赖 ModMenu 也能进配置（J 键 / 背包 ⚙）
- 局域网 / 离线服：脱裤会自动用玩家默认皮肤兜底，离线也能正常显示脱裤
- 皮肤下载失败会自动冷却重试（60 秒），无需重启
- 已知兼容性：与 e33chat 聊天气泡、Modern UI、Xaero 地图等常见 mod 无冲突

## 常见问题

**真菌感染怎么治？**
花露水倒进有水的洗脚盆 → 药水洗脚水 → 坐凳泡脚。没有别的办法（命令除外）。

**汗脚怎么消除？**
泡脚 15 秒。倒汗不清汗脚，脱鞋只降级。

**汗液瓶怎么获得？**
主手汗靴 + 副手空玻璃瓶 + 潜行右键倒汗。靴子必须已汗化（穿满 2 分钟以上）。

**为什么我 1-2 级倒出的瓶没有风味？**
这是三级质变机制（0.1.4+）：1-2 级只出普通瓶，**汗脚 3 级**倒汗才会按靴子材质质变成风味瓶。

**风味瓶的颜色代表什么？**
每种风味一个药水色（硫磺=金色、凛冽=青蓝等），颜色对应附加效果，见手册风味图鉴。

**发酵靴有护甲吗？**
有，1 点（同皮革），tooltip 上直接显示。

**喝汗液瓶回多少饱食度？**
1 点（半格）；醇厚风味翻倍 2 点。

**手册怎么获得？**
进世界自动发一本（装了 Patchouli）；背包多本自己丢。

**服务端要装吗？**
要。本 mod 是双端 mod，服务端不装玩法逻辑不生效。

**可以放进整合包吗？**
可以，MIT 协议，注明来源即可。

**按 J 没反应？**
键位可能被其他 mod 占用——进「选项 → 控制」改键，或用背包右上角 ⚙ 按钮。
