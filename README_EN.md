# Sweaty Feet

Wear boots too long and your feet get sweaty! A prank-focused Minecraft mod for NeoForge 1.21.1.

## Features

- **Sweaty Feet**: Wear any boots (`foot_armor` tag, compatible with other mods) for 2/4/6 minutes to trigger sweaty feet level 1/2/3. The boots become "Sweaty xxx" (name is restored on cleanup).
- **Extract sweat**: Hold sweaty boots + glass bottle in offhand + crouch + right-click -> the bottle becomes a Sweat Bottle and the boots are restored.
- **Sweat Bottle**: Drink it (light poison, prank yourself) or throw it while crouching (gives the target sweaty feet, prank your friends).
- **Foot Fungus**: Keep wearing boots past level 3 and you start sneezing. Cured by taking the boots off.
- **Config**: Mods list -> Sweaty Feet -> Config button (Cloth Config GUI), all values adjustable.

## Requirements

- NeoForge 21.1+
- Cloth Config v15 (optional; works without it, just no config GUI)

## Build

```bash
gradlew build
# Output: build/libs/sweatyfeet-NeoForge-1.21.1-<version>.jar
```
